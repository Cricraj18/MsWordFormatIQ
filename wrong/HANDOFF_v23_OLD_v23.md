Checks: content type for every part; every non-External rels target exists (absolute and relative, ".." escaping = REL_TARGET_UNSAFE); every attribute in the relationships namespace (r:id, r:embed, r:link, ...) in document/header*/footer*/footnotes/endnotes/comments resolves in THAT part's rels; pStyle ids exist in styles.xml (warning); sectPr has exactly one pgSz with positive numeric w/h, at most one pgMar, no repeated headerReference/footerReference type; numId (not 0) exists in numbering.xml; bookmarkStart ids unique per part; damaged XML and DOCTYPE are reported as problems.
Use in apply.ts: report = await validateDocx(outputBlob); put report.problems into the user report; if report.ok is false, tell the user in plain words.
Limits: pStyle only (not rStyle/tblStyle); no footnote id or comment id cross-checks; numbering abstractNum links not checked; tested on hand-made zips only (no real Word file).
