## FEATURES TO BUILD (all of them; plan the order below)
1. Header/footer inheritance. The output package is the TEMPLATE package (spec: template is the base, raw content is poured in). Every section of the output gets the template's header/footer references (default, first-page, even-page) through w:headerReference / w:footerReference with the template's relationship ids, plus w:titlePg (different first page) and settings.xml w:evenAndOddHeaders exactly as the template has them. A section with no references inherits the previous section's headers in Word ("link to previous"): keep that behavior when the template's sections do. Source-document headers/footers are dropped (not mixed in) unless an option "keepSourceHeaders" is added. Page number, date and other fields inside template headers stay untouched (copy the XML parts byte for byte, with their rels, images and fonts).
2. Page size presets: A4 11906 x 16838 twips, Letter 12240 x 15840, A3 16838 x 23811 (also easy to add: Legal 12240 x 20160, A5 8392 x 11906, Tabloid 15840 x 24480). Landscape = swap w and h and write w:orient="landscape". Portrait = smaller side as w. Option "use template page" (default) keeps the template's pgSz.
3. Margins: w:pgMar top, right, bottom, left, header, footer, gutter. Default = the template's first section margins. Option for custom margins (mm or inches, converted to twips, with sane limits and a check that left + right < page width). Margin change must keep header/footer distances valid (header and footer distance less than top and bottom margin).
4. Section breaks: keep the source document's section breaks (w:sectPr inside the last paragraph's w:pPr, and the final w:sectPr child of w:body) and apply page setup per section. Break type (w:type nextPage, continuous, evenPage, oddPage) is kept. Options: apply the setup to all sections, or to selected sections only; allow a landscape section for wide tables (a table wider than the portrait text width can get its own landscape section when the user asks; mark as an option, default off). Adding a NEW section break (for example before a landscape part) means inserting a w:sectPr in the pPr of the last paragraph before it.
5. Watermark: in Word a watermark is a VML shape (v:shape with v:textpath, name or id containing "PowerPlusWaterMarkObject") inside a w:pict in a header part (one in each header type used). Modes: "inherit from template" (default: it comes along because the template header parts are copied), "remove", "keep the source document's watermark", "add text watermark" (text, color, diagonal or horizontal, opacity/size) and image watermark (image part + rels). Detect a watermark in a header part by scanning its XML (the xml_rewrite tokenizer can do this).
6. Check page-size and margin edge cases: different sizes in different sections, mirrored margins (w:mirrorMargins in settings), gutter at top (w:gutterAtTop), columns (w:cols kept), page borders (w:pgBorders kept), line numbering (w:lnNumType kept), vertical text direction (w:textDirection kept), page numbering restart (w:pgNumType kept).
